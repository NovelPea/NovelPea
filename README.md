# NovelPea

NovelPea is a cozy, browser-based writing studio for organizing and drafting novels. It includes a chapter editor, story-planning tools, profile settings, and a guided introduction for new accounts.

## Features

- Create an account or log in
- Choose a pen name during signup; it cannot be changed later
- Take a skippable tutorial when creating an account
- Select preferred genres after the tutorial, or skip genre selection
- Write and organize chapters with automatic saving
- Track chapter and word counts
- Keep story details in the Story Bible, Characters, Places, and Notes sections
- Edit your full name, bio, and birthplace from your profile
- Export your manuscript as a `.txt` file
- Switch between light and dark themes

## Getting started

1. Save the app’s HTML as `index.html`.
2. Open `index.html` in a modern web browser.
3. Choose **Create account** and fill in the form.
4. Follow or skip the tutorial, then choose or skip your genres.

No installation or server is required.

## Saving and privacy

This demo stores account and writing data in your browser using `localStorage`. Data is specific to the browser and device where it was entered. Clearing browser storage may delete it. The demo does not use a secure server, so **do not enter real passwords or sensitive personal information**.
